# CodepathMail

Submitted by: **Isaac Livingston**

**CodepathMail** is an Android app that recreates a simple version of an email application like Gmail. The app displays a list of emails that the user can scroll through. Each email displays the sender, email title, and a short summary.

Time spent: **5 hours** spent in total

## Required Features

The following **required** functionality is completed:

- [x] **User can scroll through a list of 10 emails**
- [x] **Each email displays the sender**
- [x] **Each email displays the email title**
- [x] **Each email displays a summary of the email**
- [x] **Emails are displayed using a RecyclerView**

## Optional Features

The following **optional/stretch** features are implemented:

- [x] User can press a **Load More** button to display 5 additional emails
- [x] Each email displays a picture of the sender
- [x] Each email displays the date it was sent
- [x] Unread emails are displayed using bold text

## Additional Features

The following **additional** features are implemented:

- [x] Email entries are spaced using padding for a cleaner layout
- [x] Sender names are displayed in larger/bold text
- [x] Email summaries are limited to one line
- [x] Long email summaries are shortened with an ellipsis
- [x] Emails are organized vertically using a LinearLayoutManager


## Notes

One challenge during this lab was learning how the RecyclerView, Adapter, and email data classes work together. This project helped me better understand how Android apps can display and organize lists of information.
